# Внедрённые изменения

9 сентября 2026. Реализована согласованная переработка runtime-инструкций, двух
собственных skills Studio и диагностики хореографии. Исходный аудит в README
описывает состояние до этих изменений; его ссылки на номера строк относятся к
той версии. Новые правила находятся непосредственно в исходниках Studio.

## Что теперь работает иначе

- [Conventions](</Users/dev_wandry/projects/opensource/remocn-studio/sidecar/claude/conventions.ts>) выбирают направление по brief, бренду и одному основному референсу. Сняты квоты декора, веса шрифта, направлений, постоянного движения и обязательной камеры. Пользовательское направление определяет стиль; исторические технические уроки применяются по условиям.
- [Motion-design](</Users/dev_wandry/projects/opensource/remocn-studio/agent/skills/motion-design/SKILL.md>) ведёт от выбора направления к ключевым кадрам, короткому фрагменту и сравнению результата с референсом. Пять направлений и словарь движений вынесены в отдельные доступные по ссылкам руководства. Переписаны и вложенные правила, чтобы старые требования не возвращались при их чтении.
- [Video-lessons](</Users/dev_wandry/projects/opensource/remocn-studio/agent/skills/video-lessons/SKILL.md>) стал коротким указателем на технические наблюдения по шрифтам, времени, переходам, HTML/графике и рендеру. Рецепты отделены от ограничений. Убраны глобальные предписания конкретного opener, числа, оси текста, перехода и render scale; историческим обходным решениям явно заданы границы применимости.
- [Pipeline](</Users/dev_wandry/projects/opensource/remocn-studio/shared/pipeline.ts>) сохранил семь идентификаторов стадий и существующие вкладки документов. Motion теперь требует просмотренные ключевые кадры. Build начинает с рендера сложного короткого фрагмента, фиксирует его проверку в motion.md и затем расширяет монтаж. Дополнительного согласования каждой стадии не требуется. Review включает сравнение с направлением и фиксацию версии проверенного экспорта.
- [Проверка хореографии](</Users/dev_wandry/projects/opensource/remocn-studio/sidecar/preview/choreography.ts>) принимает один непрерывный шот. Неизменные кадры, равномерные длительности и отсутствие общих design-id между склейками дают информацию для сравнения с замыслом, а не обязательную правку. Неуказанная камера допустима. Явно указанный, но отсутствующий селектор по-прежнему даёт предупреждение.
- Legacy-проверка `timeline_static` также стала информационной. В full review хореография доступна и для одного шота. Проверки явно заявленного движения, отсутствующих целей, читаемости, clipping, audio, stale и неполного покрытия сохранены.
- Контракт MCP `design_check` обновлён вместе с реализацией: его описание больше не требует вернуть движение или слой ради самой метрики.

Контроль ключевых кадров и короткого фрагмента задан workflow-инструкциями и
условиями завершения стадий. Новый блокирующий валидатор наличия этих артефактов
не добавлен. Это изменение поведения агента, а не новая система разрешений на экспорт.

## Применение

Изменения внесены в этот checkout Studio, а не в уже установленный релиз приложения.
Перезапустите dev-приложение/sidecar для загрузки новых conventions и bundle skills:
Codex-копия skills кешируется на время процесса sidecar. Для установленного релиза
нужна новая сборка приложения. Старые conversations могут сохранять прежние
инструкции в истории; для чистого сравнения используйте новые сессии с одинаковыми
brief, референсом, моделью и assets.

[Промпт тестового ролика](</Users/dev_wandry/projects/opensource/remocn-studio/docs/analysis/generation-quality-2026-09-09/next-generation-prompt.md>) остаётся готовым brief для такого сравнения.
