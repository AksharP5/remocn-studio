# Визуальная карта анализа

Кадры извлечены из присланных и найденных локальных видео. Обзорные листы содержат до 20 равномерных выборок; таймкоды приблизительны. Листы помогают сравнивать композицию и последовательность, но не заменяют просмотр движения и звука. Исходные MP4 не изменены.

## Три перехода крупнее

fomo, примерно 9.2–11.7 с: слайдер → курсор → поле цены.

![fomo, примерно 9.2–11.7 с: слайдер → курсор → поле цены.](</Users/dev_wandry/projects/opensource/remocn-studio/docs/analysis/generation-quality-2026-09-09/images/fomo-handoff.jpg>)

Lovable, примерно 7.5–10.5 с: запрос → клик → приближение → готовый результат.

![Lovable, примерно 7.5–10.5 с: запрос → клик → приближение → готовый результат.](</Users/dev_wandry/projects/opensource/remocn-studio/docs/analysis/generation-quality-2026-09-09/images/lovable-action.jpg>)
