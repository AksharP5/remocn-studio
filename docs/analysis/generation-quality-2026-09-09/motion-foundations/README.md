# Проверенные сочетания

Финальный прогон: `2026-09-10T09-36-07-011Z`, Remotion 4.0.520.
11 видео прошли рендер; сохранено 412 PNG событий. Все 11 начальных кадров
совпали с ожидаемым пустым фоном. Все 15 сравнений 30/60 FPS при одинаковом
времени дали идентичные PNG. SHA-256 runtime совпадает с текущим исходным кодом.

Просмотрены начальные, промежуточные и конечные состояния: прежнего наложения
фраз нет, многострочная маска скрывает весь блок, подпись отделена от числа,
одна полоса закрывает уходящий кадр до появления следующего текста. Фотография
перекрывает уходящий заголовок; подпись появляется после раскрытия изображения.
Спокойные паузы в примерах предназначены для чтения.

Для покадрового сравнения сохранены [текст](type-portrait-30-events.jpg) и
[графика](metric-30-events.jpg). В подписях указан номер кадра при 30 FPS.
Это просмотр последовательности изображений, а не независимая оценка
предпочтения зрителями или звукового монтажа.
