# REM-377: export readiness through design_check

Approved architecture: extend the existing provider-neutral tool with an opt-in
full mode; preserve legacy frame/motion/video callers. All seven check groups
ship together. Implementation order below is not a release split.

## Contract and execution

Full mode owns sampling across the entire composition, scene interiors and
boundary neighborhoods, with adaptive refinement where text or pixels change.
A missing scene map uses a documented temporal grid. Frame/time budgets and
cancellation produce partial reports, never a clean bill of health. Execution
status belongs to each rule and is independent of finding severity.

Measurements reuse browser text/layout/contrast and choreography probes. Add
readable text histories, explicit platform/custom safe areas, resource and font
diagnostics, and rendered PCM audio analysis. Audio must use Remotion's real
mixdown, preserving Sequence, trim, speed and volume automation. Speech-related
inferences require declared speech intervals or signal evidence and are advice.
Silence, black frames and static scenes alone do not prove a defect.

Findings carry stable identity, category, measurement/heuristic classification,
observed/expected/fix context, temporal and element coordinates, and evidence.
Repeated samples merge only within a contiguous defect interval. Export defects,
intent recommendations and tunability remain distinct. Narrow intentional
exceptions bind rule, target, interval and reason to the report input revision.

Reports bind project/composition/source+asset revision, props and analysis/export
settings. Rechecking measures again, invalidates stale exceptions, and checks all
scenes after a shared component change. No unbounded automatic repair loop.

## Integration

Add a dedicated full-pass coordinator and analyzers under sidecar/preview;
keep host.ts responsible for lifecycle and protocol routing. Thread typed options
and reports through protocol, supervisor, handlers and MCP specs/execution.
Use a separately owned session for cancellable full jobs so ordinary preview
requests cannot seek the audit page. Persist evidence by report, rather than
removing the preceding report on every check. Review pipeline requests full mode.

## Verification

Unit fixtures for each analyzer include defective/fixed and intentional variants.
Renderer fixtures exercise actual text, changing backgrounds, gradual disclosure,
resource failure, audio mix clipping, boundaries and masking. Validate protocol
compatibility, budgets, cancellation, partial failures, revision invalidation,
provider exposure, typecheck and builds. Record wall time and peak memory for
short and long real renders; do not substitute mocked runtime estimates.
