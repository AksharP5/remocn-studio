# Moodboard generation (REM-266) — design

Дата: 2026-08-21. Скоуп v1: нейтральный `MoodboardSpec` + PNG-рендер + инструменты
агента + идемпотентная связка с brand-стадией пайплайна. Адаптеры Paper/Figma —
за REM-265 (пользовательские MCP) и сюда не входят.

## Решения

- **Spec — Effect Schema в `shared/moodboard.ts`**, рядом с `library.ts`. Каждая
  секция анатомии борда — массив блоков с собственным `id` (адресуемость: «замени
  третье фото» — правка spec, не новый поиск). Атрибуция — per-image
  `AssetSource` внутри spec, потому что `AssetManifest.source` — один на ассет.
- **Мудборд — обычный ассет**: `assets/<slug>/` со `spec.json`, `images/*` и
  `preview.png`; `spec.json` в `files` — маркер, `type: "img"`. Ни одного нового
  поля в манифесте: превью, undo-окно и вставка работают как есть.
- **PNG — HTML+CSS страница фиксированного холста 1440×900**, отрендеренная тем
  же путём, что скриншот brand-страницы: команда `source` превью-хоста →
  `captureSourcePage` (вьюпорт уже 1440×900, протокол не меняется). Страница
  собирается детерминированно из spec, грузится по `file://`, картинки — локальные
  файлы стейджинга; сеть на рендере — только Google Fonts (стилевой линк;
  `document.fonts.ready` уже ждётся, офлайн деградирует в fallback-стек).
  Следствие принятого в задаче: без запущенного превью проекта мудборд не
  рендерится.
- **Три инструмента на существующем сервере `remocn-library`** (тест пинит ровно
  три сервера, auto-allow выводится из того же списка):
  - `search_stock` — Pexels-поиск для курирования (клиент REM-258 переиспользован,
    ключ и сеть в сайдкаре);
  - `get_moodboard` — идемпотентная проверка: существующий борд возвращается как
    готовые spec + путь к PNG, решение принимает инструмент;
  - `save_moodboard` — скачивает выбранное, пишет spec, рендерит PNG, сохраняет
    ассет; существующий борд проекта заменяется — это и есть путь итерации.
- **Brand-стадия** (`shared/pipeline.ts`) мандатирует `get_moodboard` первым и
  описывает порядок генерации (фото → палитра из фото → шрифтовая пара → save);
  `doneWhen` требует существующий мудборд. Свободная команда «сделай мудборд»
  идёт тем же путём через абзац в `STUDIO_CONVENTIONS`.
- **Принадлежность проекту** — `spec.project`, проставляется сайдкаром из
  `params.projectId`, не агентом. v1 — мудборд на проект; с brand kit (REM-263)
  поверх ляжет бренд-скоуп.

## Отвергнутое

- Четвёртый tool-сервер `remocn-moodboard` — ломает пиннинг `TOOL_SERVERS` и не
  даёт ничего, чего не даёт `remocn-library`.
- Параметризация вьюпорта команды `source` — не нужна, пока холст равен уже
  захардкоженным 1440×900.
- Новый тип ассета `moodboard` — расползается по `ASSET_TYPE_LABELS`,
  `assetTypeFor`, карточкам и `placeAssets` ради нуля нового поведения.
