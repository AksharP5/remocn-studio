# Corner cases: ручной QA remocn-studio

Чеклист граничных случаев, ориентированный на **поведение пользователя, вёрстку и
визуал**. Каждый пункт написан так, чтобы его можно было взять и выполнить:
`ID — заголовок.` затем условия и действия, затем **Ждём:** — наблюдаемый
результат. Строки интерфейса цитируются дословно (они в коде на английском).

Условные обозначения:

- **[V]** — случай в первую очередь про вёрстку/визуал.
- **[A11y]** — про доступность и клавиатуру.
- **[P]** — про производительность и отзывчивость.
- **[D]** — про сохранность данных (потеря ввода, потеря файла, потеря истории).

Подготовка окружения, на которой держится большинство случаев:

1. Проект **A** — свежий, созданный мастером (шаблон + `bun install` прошли).
2. Проект **B** — чужая Remotion-папка, открытая через *Open Folder* (много
   композиций, свой `Root.tsx`, не `bun.lock` а `package-lock.json`).
3. Проект **C** — папка **без** `package.json`.
4. Проект **D** — папка, которую во время теста переименуют/удалят с диска.
5. Пустая библиотека ассетов и библиотека с ~40 ассетами (в т.ч. видео и звук).
6. Ключ Pexels: один прогон без ключа, один — с ключом.

## 1. Окно, панели, общий каркас

- **L-01 — Минимальные ширины трёх панелей.** Открыт проект, preview показан,
  Inspect выбрал элемент со схемой (props-панель на экране) → тянуть окно до
  ~900 px и уже. **Ждём:** chat не уже 380 px, preview не уже 360 px, props в
  диапазоне 280–560 px; ни одна панель не схлопывается сама; у окна нет
  горизонтальной прокрутки; контролы композера сворачиваются в иконки, а не
  переполняют строку.
- **L-02 — Сохранённая раскладка двух панелей не подставляется в три. [D]**
  Растянуть preview до 70 %, закрыть props-панель (Cancel), перезапустить
  приложение → открыть Inspect на элементе со схемой. **Ждём:** ширины chat и
  preview восстановлены как в двухпанельном состоянии; появление props не
  «съедает» их пропорции неожиданно — раскладка трёх панелей своя (`panelIdsOf`
  даёт другой id-лист).
- **L-03 — Схлопывание preview анимируется без дёрганья iframe. [V][P]**
  Нажать «Hide the preview» и сразу «Show the preview» несколько раз подряд.
  **Ждём:** во время слайда iframe **не** пересчитывает размер каждый кадр
  (`FrozenPane` фиксирует ширину, прижимая пане к правому краю и обрезая);
  после анимации — один перелив; плеер не мигает чёрным.
- **L-04 — Схлопывание сайдбара и кнопка возврата. [V]** Скрыть список проектов
  (иконка `PanelLeftClose`). **Ждём:** grid-колонка уходит в `0rem` за 250 ms;
  в шапке чата появляется кнопка «Show the project list», выезжающая с
  `w-0 → w-8` и `opacity 0 → 1`; заголовок панели смещается на
  `--titlebar-inline-inset`, чтобы не залезть под «светофор» macOS.
- **L-05 — Скрытый сайдбар недоступен с клавиатуры. [A11y]** Скрыть сайдбар →
  жать Tab по кругу. **Ждём:** фокус не попадает внутрь скрытой панели
  (`inert={!isProjectsShown}`); скрытая кнопка «Show the project list» тоже
  инертна, когда сайдбар открыт.
- **L-06 — `prefers-reduced-motion`. [V][A11y]** Включить «Уменьшение движения»
  в macOS → скрыть/показать сайдбар и preview, открыть drawer плана,
  переключить вид панели. **Ждём:** `motion-reduce:transition-none` убирает
  слайды панелей и полей; при этом ничего не ломается по геометрии, контент
  сразу на конечных позициях.
- **L-07 — Перетаскивание окна за шапку. [V]** Тянуть окно за пустое место
  шапки чата, за шапку preview, за строку с логотипом. **Ждём:** окно
  двигается (`data-tauri-drag-region`); тянуть за кнопки/заголовки, которые
  являются контролами, окно **не** должно.
- **L-08 — Полноэкранный режим.** View → Fullscreen. **Ждём:** шапка-полоса
  остаётся той же высоты, ничего не наезжает на края; выход из fullscreen не
  ломает раскладку панелей.
- **L-09 — Очень широкое окно (2560 px+). [V]** **Ждём:** транскрипт и композер
  остаются в колонке `max-w-2xl` по центру; drawer плана/очереди строго уже
  композера на `px-3` и выглядит «выезжающим из-за него», а не отдельной
  плашкой; preview центрируется и не растягивается за пределы соотношения.
- **L-10 — Очень маленькое окно (минимальный размер macOS). [V]** **Ждём:**
  сайдбар (18 rem) + chat (380 px) + preview (360 px) не влезают — проверить,
  что окно физически не даёт стать уже суммы минимумов, либо панель preview
  корректно схлопывается, а не рвёт вёрстку.
- **L-11 — Разделитель между chat и preview при скрытом preview. [V]**
  **Ждём:** handle с `opacity-0` и `disabled` — курсор не превращается в
  ресайз, потянуть нельзя.
- **L-12 — Props-панель исчезает при снятии выделения.** Открыть props-панель →
  Cancel. **Ждём:** панель размонтируется полностью (а не остаётся пустой
  рейкой), chat/preview забирают её ширину; повторный Inspect возвращает
  сохранённую ширину props.
- **L-13 — Смена темы не сбрасывает раскладку. [V]** Настроить ширины →
  Settings → Appearance → Light → Dark. **Ждём:** ширины панелей те же;
  нигде не «мигает» белым при переключении (фон `body` задан токеном).
- **L-14 — Шейдер в шапке при 0 проектов.** Первый запуск, проектов нет.
  **Ждём:** `mood === null` — полоса шапки той же высоты, но **без** шейдера;
  ничего под ней не сдвигается, когда первый проект появляется и шейдер
  включается.
- **L-15 — Настроение шапки меняется по состоянию. [V]** Запустить турн →
  довести до permission-карточки → уронить турн ошибкой. **Ждём:** тон полосы
  идёт `idle → waiting (-hue-rotate-45, синий) → failed (hue-rotate-100,
  красный)`, переход плавный 700 ms; скорость шейдера растёт, когда турн идёт.
- **L-16 — Ресайз во время идущего турна. [P]** Тянуть разделитель, пока
  стримится ответ. **Ждём:** текст перетекает без рывков, автоскролл
  транскрипта не срывается, таймер «Thinking» не сбрасывается.

## 2. Список видео и чатов (левая панель)

- **S-01 — Пустой проект.** Проект открыт, видео нет. **Ждём:** «No videos
  yet.», кнопка «New video» активна, скелетоны не висят.
- **S-02 — Проект не открыт.** **Ждём:** пустое состояние «No project open» с
  подписью «Create one, or open a folder you already have.», кнопка «New video»
  **disabled**.
- **S-03 — Загрузка. [V]** Открыть проект с большой историей. **Ждём:** четыре
  `SidebarMenuSkeleton` с иконкой; после загрузки скелетоны заменяются рядами
  без скачка высоты панели.
- **S-04 — Ошибка истории.** Уронить sidecar / сломать БД. **Ждём:** «History is
  unavailable» + текст ошибки с переносом по словам (`break-words`, длинный
  путь не рвёт панель) и кнопка «Try again».
- **S-05 — Больше 8 тихих чатов.** Видео с 15 завершёнными чатами. **Ждём:**
  видно 8, ниже «Show 7 more»; после раскрытия — «Show less»; число всегда
  совпадает с тем, сколько реально появилось.
- **S-06 — Лимит не прячет то, что требует внимания.** 12 тихих чатов + 1
  running + 1 waiting + 1 unread. **Ждём:** running/waiting/unread показаны
  всегда и **не** попадают в счётчик «Show N more».
- **S-07 — Порядок внутри видео.** Одновременно waiting (два, с разным
  временем), running и обычные. **Ждём:** сверху waiting, среди них — тот, кто
  ждёт дольше; затем running; затем остальные в исходном порядке.
- **S-08 — Продвижение группы наверх.** Видео №3 получает permission-запрос.
  **Ждём:** его группа поднимается выше остальных, относительный порядок
  прочих не меняется.
- **S-09 — Rollup «худшее из».** В свёрнутой группе одновременно waiting (2),
  running, failed, unread. **Ждём:** на строке видео показан только waiting со
  счётчиком «2»; `aria-label` читается «2 chats waiting».
- **S-10 — Rollup исчезает при раскрытии.** Раскрыть группу. **Ждём:** значок
  rollup пропадает (он только для свёрнутого состояния), шеврон повернулся на
  90°.
- **S-11 — Видео, которого нет в коде.** Удалить папку `src/videos/<slug>` →
  дождаться реконсиляции. **Ждём:** видео уезжает в секцию «Not in the code»,
  имя приглушено (`text-sidebar-foreground/70`), шеврон и меню — полной
  контрастности; появляется иконка `FileQuestion` с тултипом «Nothing in this
  project renders <slug> anymore»; кнопка «New chat here» **disabled**.
- **S-12 — Регистрация «потерянного» видео.** Меню видео в «Not in the code» →
  «Register in this project». **Ждём:** пункт есть только у missing-видео; после
  успеха видео возвращается в активную секцию без перезапуска.
- **S-13 — Удаление видео и Undo. [D]** Меню → «Delete video» → подтвердить.
  **Ждём:** диалог явно говорит, что файлы на диске остаются; строка исчезает
  мгновенно; тост с Undo; Undo возвращает видео **и его чаты** на прежнее
  место; папка на диске в обоих случаях не тронута.
- **S-14 — Удаление чата и Undo в пределах 10 с. [D]** Удалить чат → Undo.
  **Ждём:** строка возвращается **на тот же индекс**, выделение тоже
  восстанавливается.
- **S-15 — Выход из приложения внутри окна Undo. [D]** Удалить чат → сразу Quit
  → запустить снова. **Ждём:** чат **на месте** (удаление отменено, а не
  «доехало»).
- **S-16 — Занятый чат нельзя удалить.** Пока турн running/waiting. **Ждём:**
  кнопка корзины **не отрисована** вовсе (`busy ? null : …`).
- **S-17 — Наведение ничего не скрывает. [V]** Навести на строку с running/
  waiting/failed. **Ждём:** маркер состояния слева остаётся видимым, кнопка
  удаления появляется в своём слоте справа и ничего не перекрывает.
- **S-18 — Очень длинное имя видео и чата. [V]** Имя в 200 символов, без
  пробелов. **Ждём:** одна строка с `truncate`, панель не расширяется, кнопки
  «New chat»/«…» остаются на месте (`pr-14` резерв), тултип/`title` не
  обязателен, но лейаут не должен ломаться.
- **S-19 — Кириллица и эмодзи в имени. [V]** «Интро 🎬 для клиента».
  **Ждём:** отрисовано корректно (`--font-cyrillic` подхватывается), эмодзи не
  ломает базовую линию строки, обрезание по `truncate` не режет символ пополам
  визуально грязно.
- **S-20 — Двухстрочная строка чата. [V]** Waiting/running/failed. **Ждём:**
  вторая строка: `Waiting 4m · Bash`, `Registering the scene · 1/3 · 2m`, или
  первая строка ошибки; текст `truncate`, `tabular-nums` — цифры не «прыгают»
  при тике раз в минуту.
- **S-21 — Таймер ожидания растёт. [P]** Оставить permission-карточку без
  ответа на 3 минуты. **Ждём:** «Waiting 1m → 2m → 3m», обновление раз в
  минуту; таймер считает **вверх**, не «осталось».
- **S-22 — Ошибка в несколько строк.** Турн упал с многострочной ошибкой.
  **Ждём:** в строке чата — только первая непустая строка, полный текст — в
  транскрипте.
- **S-23 — Точка «непрочитано».** Запустить турн, переключиться на другой чат,
  дождаться завершения. **Ждём:** у фонового чата появляется точка; открыть
  его — точка исчезает.
- **S-24 — Переключение вида панели: направление слайда. [V]** Videos → Assets
  → Components → Videos. **Ждём:** вперёд `animate-screen-in`, назад
  `animate-screen-back`; при возврате на тот же вид анимации нет.
- **S-25 — Активный вид отмечен рейкой. [V]** **Ждём:** тонкая полоска
  `w-0.5 h-4` у левого края, вес шрифта **не** меняется между состояниями
  (лейблы не «дёргаются»), фон активного пункта прозрачный.
- **S-26 — Сохранение раскрытых видео. [D]** Раскрыть 3 группы → перезапуск.
  **Ждём:** те же группы раскрыты.
- **S-27 — Скролл длинного списка и sticky-заголовки. [V]** 30 видео + вид
  Components с группами. **Ждём:** поле поиска sticky на `top-0`, заголовки
  групп sticky на `top-11`, карточки проезжают **под** ними, а не сквозь фон.
- **S-28 — Клавиатура по списку. [A11y]** Tab по строкам. **Ждём:** у каждой
  строки чата видимое кольцо `focus-visible:ring-2 ring-sidebar-ring`, кнопка
  удаления получает фокус и становится видимой (`focus-visible:opacity-100`).
- **S-29 — Скринридер читает состояние строки. [A11y]** VoiceOver на строке
  running. **Ждём:** читается «<title> is running», маркер имеет `role="img"`,
  а не live-region (иначе он переобъявлялся бы при перестановке строк).

## 3. Композер: текст, ссылки, отправка

- **C-01 — Enter отправляет, Shift+Enter переносит.** **Ждём:** ровно так; при
  открытом списке `@`-упоминаний Enter **выбирает файл**, а не отправляет.
- **C-02 — Enter при пустом поле.** **Ждём:** ничего не происходит, поле не
  очищается, кнопка отправки `disabled`.
- **C-03 — Только пробелы.** Ввести «   » → Enter. **Ждём:** отправки нет
  (`value.trim().length > 0`), но если приложены картинки/ассеты — отправка
  разрешена.
- **C-04 — Отправка при упавшем sidecar.** Остановить sidecar → набрать текст.
  **Ждём:** кнопка отправки `disabled`, под композером «The sidecar is not
  running.» + ссылка «Restart it»; текст **не теряется**.
- **C-05 — Отправка во время идущего турна ставит в очередь. [D]** **Ждём:**
  кнопка меняется на «Queue» с иконкой; после клика поле очищается **только**
  если сообщение реально принято; сообщение видно в drawer очереди.
- **C-06 — Ввод при заблокированном композере не теряется. [D]** Дождаться
  permission-карточки. **Ждём:** textarea `disabled`, placeholder «Answer the
  approval request to continue…»; уже набранный текст и вложения остаются
  после ответа на карточку.
- **C-07 — Вставка картинки по ⌘V.** Скопировать PNG в буфер → ⌘V в композере.
  **Ждём:** карточка-превью появляется в блоке вложений, в тексте на позиции
  каретки — `[Image #1]` цветом `--reference`; каретка сразу после токена.
- **C-08 — Вставка нескольких картинок разом.** Скопировать 3 файла.
  **Ждём:** `[Image #1][Image #2][Image #3]` вставлены подряд, три карточки,
  нумерация совпадает с порядком карточек.
- **C-09 — Backspace на границе токена удаляет токен целиком.** Каретка сразу
  после `[Image #1]` → Backspace. **Ждём:** токен исчезает **целиком**,
  соответствующая карточка удаляется, номера выше сдвигаются вниз.
- **C-10 — Delete внутри токена.** Каретка в середине `[Image #2]` → Delete.
  **Ждём:** то же: токен и вложение уходят вместе.
- **C-11 — ⌘A + Delete.** **Ждём:** текст пуст, **все** вложения/выделения/
  ассеты сняты (путь через `lostReferences`), карточки исчезли.
- **C-12 — Вырезать токен (⌘X).** Выделить `[Image #1]` → ⌘X. **Ждём:**
  вложение снято; вставка обратно (⌘V текстом) **не** возвращает вложение —
  токен становится обычным текстом и не подсвечивается.
- **C-13 — Option+Backspace (удаление слова).** Каретка после токена →
  ⌥⌫. **Ждём:** обработка идёт через diff-путь `onChange`; вложение снимается,
  каретка в разумном месте, текст не «разъезжается».
- **C-14 — Номер больше числа вложений — не ссылка. [V]** Приложить 2 картинки,
  вручную напечатать `[Image #7]`. **Ждём:** `#7` — обычный текст, **не**
  подсвечен, и в отправленное сообщение ничего не вклеивается.
- **C-15 — Повторная ссылка на одну картинку.** Написать `[Image #1] ... [Image
  #1]`. **Ждём:** обе подсвечены; при отправке картинка уходит один раз,
  повтор остаётся текстом.
- **C-16 — Удаление вложения крестиком на карточке.** **Ждём:** токен из текста
  исчезает, номера выше пересчитываются, текст вокруг не меняется.
- **C-17 — Синхронизация каретки с оверлеем. [V]** Набрать 5 строк текста c
  4–5 `[Image #N]` вперемешку, поставить каретку в разные места, прокрутить
  textarea. **Ждём:** каретка стоит ровно на границе символа — оверлей и
  textarea имеют одинаковую типографику; при прокрутке оверлей едет синхронно
  (`caret.onScroll`); ссылка отличается **только цветом**, не весом/трекингом.
- **C-18 — Textarea растёт до предела. [V]** Ввести 60 строк. **Ждём:** поле
  растёт (`field-sizing-content`) до `max-h-64`, дальше — своя прокрутка;
  `scrollbar-gutter: stable` не даёт тексту прыгать при появлении скроллбара;
  drawer плана/очереди остаётся приклеенным сверху.
- **C-19 — Узкий чат: чипы сворачиваются. [V]** Сузить chat до ~420 px и
  меньше. **Ждём:** Effort прячет подпись первым (`@max-md/composer`), затем
  Mode (`@max-[23rem]`); Model остаётся с `truncate`; кнопки не переносятся на
  вторую строку и не выходят за границу.
