# Motion proof fixtures

This is a render workbench, not a project template or a finished marketing video.
Its metric is synthetic. `scripts/motion-proof.ts` copies the fixture together with
the exact shipped motion module into an isolated Remotion project.

Reference decisions:

- **Type:** the supplied Unity reference (`mi9mwKtAjPQuPHrW.mp4`) demonstrates the
  restraint of one central regular-weight statement. This fixture tests that
  hierarchy and reading cadence; it does not claim to reproduce its exact curve.
- **Image:** the supplied Seedance reference (`_Vqe8gOHj1g9kX92.mp4`) separates the
  image's role from light accompanying type. Here an owned image mask completes
  before the caption's reading interval; no footage or audio timing is evaluated.
- **Metric:** the supplied cajobo and Cloudflare references (`2FLsTfmfrs_fz7e1.mp4`,
  `LtDRmo2bVZySoIKZ.mp4`) develop graphic forms across beats. Here the same line that
  accompanies a number becomes the next background, with one geometry owner.

These are adaptations of selected decisions, not shot-for-shot recreations.
The proofs vary content, aspect ratio and FPS; they do not establish blind
preference or a reduction in user corrections to model-generated videos.
